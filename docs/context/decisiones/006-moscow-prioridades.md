# ADR-006: MoSCoW como método de priorización

**Estado:** APROBADA

## Decisión

Usar el método **MoSCoW** para priorizar requerimientos en reglas de negocio y funcionales.

## Categorías

| Categoría | Significado | Alcance |
|-----------|-------------|---------|
| **Must** | Obligatorio para entrega | Sprint 1-4 |
| **Should** | Importante, alta prioridad | Sprint 3-6 |
| **Could** | Deseable si hay tiempo | Sprint 5-8 |
| **Won't** | Fuera de alcance v1.0 | Post-lanzamiento |
